# Siyafunda AI Chatbot

## About the Project

Siyafunda AI Chatbot is an interactive educational chatbot developed as a group project during the CAPACITI Service Desk Cohort 2 programme.

The project was designed to make foundational Artificial Intelligence concepts easier for beginners to understand through conversational learning.

The chatbot provides structured learning modules, guided conversation flows, questions, quizzes, and interactive learning elements.

## Project Objectives

- Simplify complex AI concepts for beginners
- Support self-paced learning
- Improve understanding through interactive and multimedia elements
- Provide a structured conversational learning experience

## Key Topics Covered

The chatbot covers foundational AI topics including:

- Artificial Intelligence
- Machine Learning
- Deep Learning
- Neural Networks
- Natural Language Processing
- Computer Vision
- Large Language Models
- AI Ethics and Responsible AI

## Key Features

- Guided learning modules
- Structured conversation flows
- Beginner-friendly AI explanations
- Interactive questions and answers
- Multimedia learning elements
- Knowledge quiz
- Certificate pathway

## How It Works

The chatbot begins with a welcome interaction and allows the learner to select their user type and learning needs.

Users can then:

1. Select a learning module
2. Explore an AI topic
3. Read explanations and examples
4. Ask questions
5. Continue to another module or return to the syllabus
6. Complete a quiz to test their knowledge
7. Receive a certificate after passing the quiz

## Platform

The chatbot was developed using **Botpress**.

Botpress was selected because its visual interface makes it possible to design structured conversation flows and incorporate interactive and multimedia elements.
